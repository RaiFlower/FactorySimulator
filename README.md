# FactorySimulator

A Factorio-style factory simulation game built with [MonoGame](https://monogame.net/) and C#.

## Project structure

- `FactorySimulator.Core` – game code
- `FactorySimulator.Content` – content builder project (assets)
- `FactorySimulator.DesktopGL` – desktop launcher

## Build and run

```bash
dotnet build
dotnet run --project FactorySimulator.DesktopGL
```
